💡 Boas Práticas para Maximizar a Performance no Sistema

  1. Debounce de 700ms: Aguardar o usuário terminar a digitação do nome de usuário antes de disparar o fetch.
  2. Consulta Sob Demanda: Buscar apenas os dados de perfil no primeiro momento; buscar o feed de publicações apenas se o plano for de curtidas/visualizações.
  3. Cache de Sessão: Salvar o resultado da consulta por 15 minutos para não gastar créditos caso o cliente clique fora e abra o modal de novo.
